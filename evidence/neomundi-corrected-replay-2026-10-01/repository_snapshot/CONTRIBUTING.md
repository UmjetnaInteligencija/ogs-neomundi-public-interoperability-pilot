# Contributing

This repository is not currently accepting unsolicited code contributions or pull requests.

The pilot contains joint-attribution, evidence-boundary, and intellectual-property considerations that require controlled review. Proposed corrections should identify:

- the exact file and passage;
- the factual or technical issue;
- the supporting source or reproducible counterexample;
- whether the correction affects evidence status, attribution, or the public claim boundary.

Do not submit confidential material, credentials, customer data, private partner correspondence, or proprietary implementation details through GitHub issues or pull requests.
