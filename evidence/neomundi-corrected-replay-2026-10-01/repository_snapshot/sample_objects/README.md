# Public Example Objects

These objects are **illustrative public examples**, not historical pilot artifacts.

Each file contains:

```text
example_status: illustrative_public_example_not_historical_pilot_artifact
```

The examples demonstrate:

- public interface fields;
- measurement limitations;
- separation of signal from intended use;
- bounded reliance and no-bind outcomes;
- object cross-references;
- deterministic integrity digests;
- replay-record structure;
- zero external action authorization.

They must not be counted among the five verified private-pilot cases.
