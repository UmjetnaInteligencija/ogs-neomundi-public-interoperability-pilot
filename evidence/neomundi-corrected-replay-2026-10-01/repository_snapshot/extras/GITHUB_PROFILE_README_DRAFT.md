# Mark Mocnaj

Founder and systems architect working on **Operational Governance Systems / Project Petunia × Judicator** — a non-traditional AI evaluation and runtime-governance architecture.

## Core focus

- separating generation, judgment, knowledge, institutional standing, and execution authority;
- admissibility-first evaluation;
- agent and workflow execution control;
- governance objects, receipts, replay, and outcome review;
- multi-model and enterprise interoperability;
- contribution provenance and derivative advantage.

## Public work

### NeoMundi × OGS — Measurement Is Not Authority

A synthetic interoperability proof of method showing how runtime risk and drift observations can become bounded governance objects, review obligations, no-bind outcomes, receipts, and replayable evidence without measurement becoming execution authority.

## Doctrine

```text
generation ≠ judgment
judgment ≠ knowledge
knowledge ≠ execution authority
reasoning ≠ admissibility
measurement ≠ authority
```
