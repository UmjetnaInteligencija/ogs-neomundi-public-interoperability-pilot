# Final Release Sequence

1. Upload RC repository privately.
2. Run repository verifier and preserve transcript.
3. Add NeoMundi reviewer as collaborator, if agreed.
4. Resolve wording, signal-field, diagram, brand, attribution, and evidence-archive decisions.
5. Complete approval checklist and sign-off table.
6. Remove `rc` status only after approval.
7. Rerun verifier.
8. Generate final manifest, ZIP, and SHA-256.
9. Create final Git tag and GitHub Release.
10. Change repository visibility to public.
11. Add repository link to Judicator.eu.
12. Publish LinkedIn article/post with the controlled claim.
13. Preserve screenshots, release URL, tag, commit hash, ZIP hash, and publication timestamp in the project provenance record.
