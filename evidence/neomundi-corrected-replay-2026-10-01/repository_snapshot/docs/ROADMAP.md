# Roadmap

## v1.1.0 final — joint public documentation release

Required:

- partner technical and brand sign-off;
- final attribution and conclusion;
- final repository validation;
- approved decision on whether the corrected evidence archive is attached;

## v1.2 — independent reproduction pack

Target:

- frozen corrected evidence archive;
- clean-room instructions;
- exact replay command;
- external operator transcript;
- independently generated receipts and replay record;
- E6 evidence classification if the result is reproduced.

## v2.0 — live interoperability pilot

Potential scope, subject to separate agreement:

- live API exchange;
- explicit identity and authority interfaces;
- changed-condition replay;
- richer measurement-limitations fields;
- domain-specific signal classes;
- external receipt anchoring;
- auditor or regulator observation;
- no production or safety claim without corresponding evidence.
