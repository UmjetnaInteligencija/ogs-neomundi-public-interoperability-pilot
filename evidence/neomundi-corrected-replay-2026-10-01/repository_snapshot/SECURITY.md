# Security Policy

## Scope

This repository contains documentation, public-safe schemas, and illustrative objects. It is not a production service and does not expose a live execution endpoint.

## Reporting

Report security-sensitive concerns privately to the project contact route rather than through a public issue. Do not include credentials, private evidence archives, customer data, or exploitable details in a public report.

## Claim boundary

The repository verifier performs local integrity and consistency checks. It does not provide cryptographic non-repudiation, malicious-insider resistance, independent timestamp assurance, HSM/KMS custody, external anchoring, or production security certification.
