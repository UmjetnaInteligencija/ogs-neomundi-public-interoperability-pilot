# Evidence Classification

| Class | Definition | Present here? |
|---|---|---|
| E0 | Assertion without identified artifact | No controlled result relies on E0 |
| E1 | Reported summary | Historical background only |
| E2 | Source artifact located; chain incomplete | Public specification and illustrative examples |
| E3 | Input and case-level outcome trace present | Yes, in referenced corrected private pack |
| E4 | Receipt-backed case-level result | Yes, in referenced corrected private pack |
| E5-internal | Internal deterministic replay | Yes: 5 passed, 0 failed |
| E6 | Independently reproduced | No |
| E7 | Production evidence | No |

## Release language rule

Evidence class must travel with the claim. A public statement must not omit the words `synthetic`, `internally verified`, and `not independently reproduced or production-derived` when describing the verified result.
