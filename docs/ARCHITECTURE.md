# Architecture

```text
Runtime System
→ NeoMundi Measurement Layer
→ Versioned Signal Object
→ OGS Injector / Petunia / DPA
→ CAOM Governance Object
→ Judicator Consequence Boundary
→ Receipt
→ Replay and Audit
```

## Control boundaries

- NeoMundi observes and structures runtime signals.
- OGS evaluates permitted reliance and downstream consequence.
- No measurement signal creates execution authority.
- This public pilot does not execute external actions.

## Non-collapse doctrine

```text
observation ≠ evidence
measurement ≠ truth
risk signal ≠ authority
admissibility ≠ execution permission
receipt ≠ certification
```
