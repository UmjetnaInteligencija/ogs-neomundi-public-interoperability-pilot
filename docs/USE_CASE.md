# Use Case

A runtime system may appear stable while retaining factual fragility, uncertainty, or contradiction risk. NeoMundi supplies structured runtime measurements. OGS determines whether those measurements may remain observations, become bounded internal hypotheses, require review, or be refused as claims or execution triggers.

The pilot demonstrates:

```text
runtime measurement
→ NeoMundi signal
→ OGS epistemic and consequence admissibility
→ bounded outcome
→ receipt
→ replay
```
